# Connect IQ apps by sebkraemer

Small add-ons for Garmin watches that fill gaps in the built-in features.

| App | Type | What it does |
|---|---|---|
| [Set RPE](set-rpe/) | Data field | Rate the perceived exertion (RPE 1–10) of every set in the Strength activity |
