# Set RPE – Privacy

_Last updated: 2026-10-28_

Set RPE is a data field for Garmin watches. It is free and made by an individual developer (sebkraemer), not by Garmin.

## What the data field stores
While the data field is on a data screen of an activity, it writes two values into that activity's FIT file:
- **RPE per set** (1–10), the value you apply on the watch, or no value if you skip
- **Set counter**, used to match each value to its set

Nothing else is stored, and nothing is stored outside the activity file.

## Where the data goes
The activity file stays on your watch until your watch syncs it to your Garmin Connect account, like every other activity. From then on Garmin processes it under [Garmin's privacy policy](https://www.garmin.com/privacy/).

## What the developer receives
**Nothing.** Set RPE has no internet access, no analytics, no account and no settings. It only uses the permission to write fields into the activity file. I never see your data.

## Deleting your data
The values are part of the activity. Deleting the activity on your watch or in Garmin Connect deletes them.

## Health note
RPE is your own rating of how hard a set felt. Set RPE is not a medical device and does not give medical advice.
